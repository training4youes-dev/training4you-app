## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Pendiente del proyecto

Lista viva: `docs/legales/PENDIENTES.md` y regla `.cursor/rules/pendiente-proyecto.mdc`.

Al final del proyecto, recordar completar los corchetes legales de Emma (Registro Mercantil, URL app, plazos, transferencias, etc.) en `/aviso-legal`, `/privacidad` y `/cookies`.
